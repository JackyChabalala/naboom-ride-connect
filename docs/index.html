Naboom Ride Connect

A fixed-price ride platform for Naboomspruit (Mookgophong) — built because Uber and Bolt do not operate here, and people were already organising their own lifts with set fares.

View on GitHub How to run the demo

Why this exists

In Mookgophong there is no Uber. Locals still need rides, so people started arranging their own transport and charging fixed prices for common routes. That works — but it is hard to manage who is available, who is trusted, and what the fare is.

Naboom Ride Connect turns that local practice into a simple digital platform: same fixed-price idea, with passenger requests, driver acceptance, admin verification, and ratings after the trip.

How it works

  • Passengers pick a route, enter a pickup point, request a ride, then rate the driver.
  • Drivers register, get approved, go available, accept rides, and complete trips.
  • Admins verify drivers, monitor rides, ratings, and emergency alerts.

Run it on your computer

GitHub Pages can only host this info page. The full app needs a server and database, so run it locally from the repo. 

git clone https://github.com/JackyChabalala/naboom-ride-connect.git
cd naboom-ride-connect
npm install
npx prisma migrate dev
npx prisma db seed
npm run dev

Then open http://localhost:3000. Demo OTP for all accounts: 123456.
